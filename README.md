# enso-india-srilanka-monsoon
# Influence of ENSO in Indian and Sri Lankan Monsoon Rainfall

Term project analyzing the relationship between the Oceanic Niño Index (ONI) 
and monthly rainfall across India and Sri Lanka (1996–2025), using CHIRPS 
precipitation and NDVI data, with an applied outlook for the 2026 El Niño event.

## Contents
- `El_Nino_India_SriLanka_Monsoon.ipynb` — full analysis notebook
- `main.tex` / `refs.bib` — LaTeX report source
- `MISTAKES_AND_FIXES.md` — development log of issues encountered and resolved

## Key finding
India and Sri Lanka both show statistically significant ENSO sensitivity, 
but in different seasons — India in August–October, Sri Lanka in October 
(wet) and February–April (dry).
